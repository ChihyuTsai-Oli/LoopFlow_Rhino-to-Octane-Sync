---

## A. 開案

1. 隔離 1.x／2.0 LiveLink。
2. 已存檔 `.3dm`；`R2O_Open`＋Health。
3. Octane：指標／手動路徑（XF-ED-04）。

---

## B. Models → Camera → Point → Scatter

### B1. Models

4. `R2O_Models` → 後處理驗證 → atomic USDZ。
5. Octane：**手動置換** last-good（ED-02＝A）。

### B2. Camera

6. Rhino 持續寫 JSON（trailing write）；Octane real-time 可關，關＝Ctrl+Q 一次。Thin Lens 須 Expand out。

### B3. Point

7. `type_id` 不寫回 Rhino；JSON 發布；缺 Proxy／未知 type 略過報告。
8. 刪 type：權威套用後刪受管節點（ED-10＝A）。資產 Block 建議放 `USD::`，勿進 Point 掃描層。

### B4. Scatter

9. 建 Block 前先擺正（±X／±Y）、插入點在 `(0,0,0)`；與 USD 差直角則在定義內旋轉（權威寫法見 `../工作流程.md`）。
10. `R2O_Scatter`（接在 Point 後）；單項失敗可繼續；**匯出結束後**來源 Block 不得留在原點。

---

## C. 第二輪

改模型 → Models＋手動置換；改視角／點／Block → Camera／Point／Scatter。

## D. 失敗停點

未存檔停；後處理失敗 last-good 不動；半寫 JSON 不 apply；real-time lag → 關輪詢。

## E. 最小可測

Health → Camera 手動 → Point → Models → Scatter → 最後試 Camera 輪詢。

## F. 不涵蓋

Authoring 擴充；自動升級；Models LiveLink。
