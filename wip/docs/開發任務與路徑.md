# LoopFlow R2O 2.0 — 開發任務與路徑

契約以 `資料契約.md` 為準；即時狀態只記 `重構進度.md`。

## 執行規則

- **能做就做、需確認再停**（R2B／R2O 共用開發原則）：AI 在已決契約與本檔範圍內直接推進文件、空殼、可自動驗證的實作並提交推送短期分支；僅在下列情況停下來問使用者——改已決 ED／ECO、凍結使用者可見名稱／檔名／package 顯示名、破壞性操作、本機安裝正式 runtime、或與決策明顯衝突無法用「2.0 修正」帶過。
- 一次一個 repo／一台電腦／一個 AI。
- 從 `v2-development` 建 `codex/v2-<scope>`。
- **可測＝兩端同批**：Rhino＋Octane Lua 同一功能同批；Models 的「消費」＝第一次載入 `R2O.usdz`，之後關再開 Octane 重讀；Objects 的「消費」＝自行載入時戳 USDZ（無 LiveLink；不要 Reload／Load new mesh）。
- **跨產品**：R2B 主鏈已穩；本產品可進 A01 與功能碼。
- **Octane 入口**：Git `wip/src/octane/entrypoints/`；Octane 執行於工作檔 `_LoopFlow_Config/loopflow_R2O/lua/`（`deploy_dev_lua.ps1`）。`R2O_Camera.lua`／`R2O_Point.lua` 已接；`__Open_Shortcuts.lua`／`__Setup_Shortcuts.lua` 已接 LiveLink 熱鍵；Open 仍為空殼。**新增 Octane 腳本時熱鍵先填 1.x 預設**（見 `資料契約.md`）。
- 前期規劃當原則；衝突先改決策表。
- 不把 authoring 混進 LiveLink 主鏈任務。

## 階段與任務（摘要）

| ID | 任務 | 產出重點 |
|---|---|---|
| R2O-A01～A06 | 盤點／命名／schema／Point ID／shortcut 邊界／fixtures | 只改文件；加厚契約 |
| R2O-B01～B04 | source 骨架、foundation、Rhino adapter、Octane loading | 可載入、隔離；**可含 Octane stub Lua 入口** |
| R2O-C01 | **Models 兩端** | Rhino USDZ 安全鏈＋Octane **關再開**重讀連結檔（無 LiveLink）；檔名 `models/R2O.usdz` |
| R2O-C02 | **Objects 兩端** | Rhino `models/R2O_Objects_時戳.usdz`＋Octane **自行載入**（無 LiveLink）；對齊 R2B Objects |
| R2O-D01 | **Point 兩端** | `type_id`＝完整圖層路徑；`live/point.json`；Octane 套用一次；熱鍵空白；**家中實機已通過** |
| R2O-D02 | **Camera 兩端** | JSON；Octane 套用一次（Ctrl+Q）；**B 後第一條功能**；家中中文路徑已通過 |
| R2O-E* | Open／shortcut／lifecycle | 診斷與安裝 |
| R2O-F* | Authoring baseline | 不擴充、不阻塞 |
| R2O-G01 | migration | 掃描／備份／一次轉／回滾；只測副本 |
| R2O-G02 | build／`build-release` | **Rhino `.yak`**（畫面名 `loopflow Rhino to OctaneRender Sync`）；Octane Lua 不進包、PM 說明放 GitHub。與 LoopFlow 2.0 相同：同一份 yak 上 PM＋Release；tag 不覆寫；文件資料夾戳記＝套件版號 |
| R2O-G03 | RC／`rc-validation` | 隔離端到端；成敗中斷 last-good |

任務表以本檔為準。

## 建議波次

1. 文件骨架＋發布契約＋執行時根與 R2B 對齊（已完成）。
2. A01–A06 → B 骨架（已完成）。
3. **D02 Camera**（已通過）→ LiveLink 熱鍵（已通過）→ **D01 Point**（已通過）→ **C01 Models**（已合入 `v2-development`）。**C02 Objects**（本批）→ 其餘 E–G。
4. E–G：其餘 Open／Health、authoring、**Rhino yak**、migration、RC。公開使用說明等本產品程式完成後與 R2B 一起寫。
