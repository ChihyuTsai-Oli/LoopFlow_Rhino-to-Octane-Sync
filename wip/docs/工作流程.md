# LoopFlow R2O 2.0 — 工作流程

權威操作順序。細節模擬見 `前期規劃/操作流程模擬_合併.md`；衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models → Camera → Point → Scatter**。

開發時：**Rhino 與 Octane（Lua）同一通道同批實作**。跨產品仍先做完 R2B 再全力做本產品。

## 開案

1. 隔離 1.x／2.0 LiveLink、shortcut、輸出。
2. 已存檔 `.3dm`；`R2O_Open`＋Health。
3. Octane：指標或手動路徑（XF-ED-04＝C）。

## Models

1. `R2O_Models` → 後處理驗證 → atomic USDZ。
2. Octane：**手動置換** last-good（無 Models LiveLink）。

## Camera

1. Rhino 持續寫 JSON（trailing write）。
2. Octane：**可開 real-time 輪詢**；關＝Ctrl+Q／跑一次腳本。

## Point

1. `type_id` 路徑映射；不寫回 Rhino。
2. JSON 發布；缺 Proxy／未知 type 略過並報告。
3. 刪 type：權威套用後刪受管節點（ED-10＝A）。

## Scatter

接在 Point 後；單項失敗可繼續；來源 Block 不得留原點。

## 失敗停點（摘要）

未存檔停；後處理失敗 last-good 不動；半寫 JSON 不 apply；real-time lag → 關輪詢改手動。
