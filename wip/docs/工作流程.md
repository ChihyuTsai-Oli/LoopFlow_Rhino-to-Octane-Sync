# LoopFlow R2O 2.0 — 工作流程

權威操作順序。細節模擬見 `前期規劃/操作流程模擬_合併.md`；衝突以本檔與 `資料契約.md` 為準。

## 操作主線

**Models → Camera → Point → Objects**。

開發時：**Rhino 與 Octane（Lua）同一通道同批實作**。安裝：Rhino 走 Package Manager `.yak`；Octane Lua 由 GitHub 說明安裝（不進 yak）。

開發期 Rhino 用 ScriptEditor 按鈕。正式 yak 工具列左鍵為 `! _ROCamera` 等（見 `rhino指令.md`）；裝包前不要用正式巨集測。Authoring 四支 Auto 仍是 Octane Lua，不進 Rhino 工具列。

使用操作序仍是 Models → Camera → Point → Objects。**開發波次**：相機、點位、Models、Objects、Open、Authoring 四支 Auto 已合入 `v2-development`。

## 開案

1. 隔離 1.x／2.0 LiveLink、shortcut、輸出。
2. 開啟**已存檔** `.3dm`（未存檔則發布停）。
3. `ROOpen`：英文對話框四顆等寬按鈕左到右 **Open Config → Open live → Open models → Open Docs**。摘要含設定根路徑、Camera／Point／Models／Objects last-good 時間。未存檔＝擋住（英文訊息）。**Open Docs** 開 GitHub 文件入口 `docs/README.md`（上英下中，再進各語使用說明；開發期 `v2-development`）。`config.json` 本批尚未落地（路徑仍由工作檔旁資料夾推導）。
4. Octane：指標或手動路徑（XF-ED-04＝C）。Octane **沒有**對等 Health 面板；`R2O_Open.lua` 仍為空殼。

### Open／Health（E）

| | Rhino | Octane |
|---|---|---|
| 觸發 | `ROOpen` | （無；Lua 空殼） |
| 輸入 | 已存檔 `.3dm` | — |
| 輸出 | 英文對話框；可開 Config／live／models／Docs | — |
| 不寫 | 不改來源 `.3dm`；不寫交換檔 | — |
| 擋 | 未存檔 | — |

## Models

1. 已存檔後，Rhino `ROModels` 三個英文視窗（對齊 R2B）：排除記號（預設 `//`，圖層路徑含此文字就不匯出；空白＝不排除）→ 階層圖層樹（可捲動；含子圖層）→ 勾選幾何類別（Point／Curve 預設不勾）。記住上次成功的圖層／記號／類別。
2. 寫入 `_LoopFlow_Config/loopflow_R2O/models/R2O.usdz`（`_-Export` 一律 `%TEMP%\R2O.usdz` 再拷 pending → 材質提升 → 驗證 → atomic）。失敗不碰舊檔、不必刪 last-good；不自動存 `.3dm`；結束後來源狀態還原。
3. Octane：**無** Models Lua。第一次把場景載入這份 `R2O.usdz` 並接材質。接口跟 **Rhino 材質名稱** 走（不同圖層／物件同名＝同一接口；R2O 不改材質名）。之後 Rhino 覆寫同一檔時，**不要**按 Reload mesh／Load new mesh；**關掉 Octane 再開**，已連結的 USDZ 會在啟動時跟上。這是 Studio+ 2026.4 限制（開著時不會可靠重讀連結檔）。改 Rhino 材質名＝新接口。
4. 空圖層／取消任一步／沒勾類別：停止，不發布。Camera／Point／Objects 檔不被 Models 刪掉。

## Camera

1. 已存檔後，Rhino `ROCamera` 開持續發布（作用中**透視**視埠；非透視停止）。`ROCameraPush` 手動推一次。
2. 寫入 `_LoopFlow_Config/loopflow_R2O/live/camera.json`；成功時更新 `%APPDATA%\LoopFlow\R2O\current_project.json`。
3. Octane 跑 `R2O_Camera.lua`（Ctrl+Q）：**套用目前 `camera.json` 一次即結束**。Studio+ 2026.4 無法在不鎖 UI 下做 realtime（已試視窗／輪詢）。之後每要對齊再跑一次。
4. Thin Lens Camera 須從 Render Target **Expand out** 成獨立節點；場景必須**恰好一台**。零台或多台英文說明、不改節點。
5. 熱鍵：編輯 `lua/R2O_Shortcuts.txt`（`__Open_Shortcuts.lua`）→ 跑 `__Setup_Shortcuts.lua` → 重掃 Octane 腳本資料夾。家中中文路徑已通過相機實機。

## Point

1. 已存檔後，Rhino `ROPoint` 掃 **`R2O::` 子圖層**的 Point 與 Block（含隱藏／鎖定；根層 `R2O` 本身不掃）。`USD::` 下的資產 Block 不會被掃到。
2. 寫入 `_LoopFlow_Config/loopflow_R2O/live/point.json`；成功時更新本機指標。
3. Octane 跑 `R2O_Point.lua`：**套用一次即結束**（無預設熱鍵）。Scatter 出現在**場景根**（可直接接 Geometry 輸入／輸出，不必炸開）。前綴 `R2O_Point_`。已有同名節點只改變換、不搬位置。刪除清掉此前綴且已不在 JSON 裡的受管節點。若場景裡還有舊的空 `R2O_Point` 群組，可手動刪。
4. `type_id`＝完整圖層路徑。同末層不同父＝兩個節點。改名＝新類型。Rhino 已刪的類型：下次成功套用後刪受管 Scatter。
5. 空清單仍發布／套用（用來清掉已刪類型）。缺 Proxy 不擋點位（幾何之後用 Scatter 接）。

## Objects

對齊 R2B Objects：獨立組件通道；可獨立跑。

1. 已存檔後，**先選取**物件，再跑 `ROObjects`。沒選取＝擋住。不限 Block。
2. 寫入 `_LoopFlow_Config/loopflow_R2O/models/R2O_Objects_YYMMDD_HHMMSS.usdz`（`_-Export` 一律 TEMP 再拷 pending → 材質提升 → 驗證 → atomic）。每次新檔、不覆蓋。
3. **不**搬原點。結束後還原選取、`doc.Modified`。不自動存來源 `.3dm`。
4. Octane：**沒有** Objects Lua。自己載入這份新 USDZ 當組件。不要 Reload mesh／Load new mesh。
5. 建議資產 Block 放在 `USD::`（不在 `R2O::`），才不會被 Point 掃成點位。建 Block 慣例見下。

### 建 Block 慣例（作者／資產）

1. **建立 Block 之前**：先把物件在世界裡擺「正」（建議正面朝 ±X 或 ±Y，與專案其他 USD 軸向約定一致）。
2. **再建立 Block**：定義的插入點／局部原點對齊世界 `(0,0,0)`，幾何相對該原點擺好。
3. 若與 Blender／場景 USD 模型坐向差 90／180／270：在 **Block 定義內**旋轉物件對齊即可，不必靠 Octane 端硬掰。
4. 如此 Point 送來的 instance 旋轉套在 Scatter Proxy 上時，Octane 方向才一致。

（1.x 說明只寫「原點對齊 (0,0,0)」不夠；精確意思是上列「先擺正再建 Block」。）

## Authoring（Octane；不擴功能）

與 LiveLink 分開，不讀 `camera.json`／`point.json`、不改同步主鏈。四支自 1.x 原樣；家中 Studio+ 2026.4 **已通過**。

| 腳本 | 熱鍵 | 操作 |
|---|---|---|
| `Auto_Align_Nodes` | Alt+A | 選取要對齊的 nodes 後執行，並設定間距 |
| `Auto_Convert_StdSurf_to_Universal` | Shift+M | 選取 USDZ node 後執行，將所有材質轉換為 Universal |
| `Auto_PBR_Universal` | Ctrl+Shift+T | 執行後彈窗選擇 PBR 貼圖資料夾，自動建立打包好的材質球 |
| `Auto_PBR_Switch_UV` | Ctrl+T | 在 `Auto_PBR_Universal` 材質球內，任選一個 node 後執行，切換 UV 模式 |

熱鍵：編輯 `lua/R2O_Shortcuts.txt` → 跑 `__Setup_Shortcuts.lua` → 重掃 Octane 腳本資料夾。deploy 不覆蓋已有熱鍵表。

## 失敗停點（摘要）

未存檔停；後處理失敗 last-good 不動；半寫 JSON／USDZ 不 apply。Camera：Octane 僅手動套用一次。Models：Octane 關再開才重讀已連結的 `R2O.usdz`（不要 Reload／Load new mesh）。Objects：沒選取停；每次新檔，Octane 自行載入。

## 磁碟示意（根與 R2B 對齊）

```text
<已存檔 .3dm 同層>/
  _LoopFlow_Config/loopflow_R2O/
    config.json / r2o.log
    live/camera.json（含 camera_pending.json）
    live/point.json（含 point_pending.json）
    models/R2O.usdz
    models/R2O_Objects_YYMMDD_HHMMSS.usdz
    lua/                 # 僅測檔根：開發期 Octane 入口拷貝，不是每案必有
```

本機指標（不是交換檔）：`%APPDATA%\LoopFlow\R2O\current_project.json`

## 不涵蓋

Authoring 功能擴充；Models LiveLink；自動升級混用。Octane Lua 不進 Rhino yak。
