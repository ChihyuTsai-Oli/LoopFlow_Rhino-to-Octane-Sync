- **Octane 測試執行位置**：`<LOOPFLOW_R2O_WORKFILES_ROOT>\_LoopFlow_Config\loopflow_R2O\lua\`  
  家中即 `E:\Dropbox (個人)\LoopFlow_Series\Workfiles\WIP_R2O\_LoopFlow_Config\loopflow_R2O\lua`（公司換 `D:\Dropbox\...`）。  
  換機 pull 後跑 `wip/tools/deploy_dev_lua.ps1` 拷過去。快捷鍵指這層，**不要**蓋 1.x AppData Lua。
- 空殼：`R2O_Open.lua`（Octane 端無 Health；Rhino `ROOpen` 已接）。`R2O_Camera.lua`／`R2O_Point.lua` 已接主鏈。Models／Objects 無 LiveLink Lua。
- 熱鍵：同層 `__Open_Shortcuts.lua`、`__Setup_Shortcuts.lua`、`R2O_Shortcuts.txt`。兩支腳本優先用 `debug.getinfo` 推導所在資料夾；若 Octane 未提供 `@…lua` 路徑，則備援 `%USERPROFILE%\Documents\LoopFlow\Rhino to OctaneRender Sync\lua`（該層須有 `R2O_Shortcuts.txt`）。失敗／完成改用可見 `MessageBox`，不只 Console `print`。deploy **不覆蓋**已有熱鍵表；拷完 Lua 後再跑 Setup，並重掃 Octane 腳本資料夾。修過 Git 腳本後須 **ROOpen（或重拷 Documents lua）** 再測。**新增腳本先填 1.x 預設鍵**（見 `資料契約.md`）。Authoring 四支已列入 Git 熱鍵表（`Alt+A`／`Shift+M`／`Ctrl+T`／`Ctrl+Shift+T`）；既有工作檔表須手動補行。
- Camera：Ctrl+Q／跑 `R2O_Camera.lua`＝套用一次即結束（ED-19 已試 realtime，Lua 會鎖 UI，改回 1.x）。寫唯一 Render Target 接上的相機；Thin Lens 在外面或包在裡面都可以。成功不彈窗，失敗才彈窗。2026-11-08 家中通過。
- Point：跑 `R2O_Point.lua`＝套用一次。Scatter 與 `R2O_Point_Geometry` 在 `R2O_Point` node graph 內，圖表露出幾何輸出。每次套用（含重新匯入）受管 Scatter 依名稱由左到右重排；Geometry group 不插入這排，已接好的線不重接。**公司機 Studio+ 2026.6 已通過**（含 Package Manager `2.0.10` 升版拷 Lua）。2026-11-07 家中依名稱重排已通過，進版 `2.0.13`。
- Models：**無** LiveLink。Rhino `ROModels` 三步視窗後寫 `models/R2O.usdz`（Rhino 8 的 `_-Export` 一律 `%TEMP%` 再拷 pending。Rhino 9 三個視窗置中、按鈕維持系統高度、只列最上層，接著直接開 Detailed Mesh Settings。USD 四項用預設，再帶選項字典把 usda 包進同一個 TEMP USDZ）。Octane 第一次載入該檔；材質接口＝Rhino 材質名稱（同名＝同一接口，prim 為 `material_`＋名稱）。沒指定材質時接口是完整圖層路徑。材質名與末端圖層節點名只留英文、數字與底線，其餘字元改成 `_`；加完仍相同才加 `_2`。改接到新名稱時複製匯出的 shader。匯出結束後父層先寫回各層自己的可見／鎖定。這套字元以外的名字不會建立材質接口。之後覆寫同一檔則 **關再開** 才重讀。不要按 Reload mesh／Load new mesh。2026-11-06 在 Studio+ 2026.6 已確認仍要關再開；2026.4 是較早的確認。Lua 鎖畫面仍只標 2026.4。改成這個名稱的第一次重匯要重接一次。
- Objects：**無** LiveLink。Rhino `ROObjects` 先選再匯，寫 `models/R2O_Objects_YYMMDD_HHMMSS.usdz`（不覆蓋）。可見／鎖定還原與材質後處理跟 `ROModels` 同一套。Octane 自行載入該 USDZ。
- Open：Rhino `ROOpen` 英文對話框四顆等寬 **Open Config → Open live → Open models → Open Docs**。摘要含 Camera／Point／Models／Objects last-good。Open Docs 開 GitHub `docs/README.md`（`main`）。Octane `R2O_Open.lua` 仍為空殼。
- Authoring 工具維持獨立腳本組（四支 Auto 與 LiveLink 同資料夾、不同職責），不塞進 LiveLink 主鏈、本輪不擴功能。**家中已通過**。操作見 `工作流程.md`：對齊 nodes（Alt+A）／USDZ 材質轉 Universal（Shift+M）／建 PBR 材質球（Ctrl+Shift+T）／材質球內切 UV（Ctrl+T）。

### 本機「文件\LoopFlow」戳記

正式指令把 yak `templates/` 裡的 Lua 拷到 `%USERPROFILE%\Documents\LoopFlow\Rhino to OctaneRender Sync\lua\`：

- 戳記檔名是套件 `templates/.loopflow_yak_version`（拷到 lua 資料夾後同名）。**內容必須等於當次 `manifest.yml` 的 `version:`。**
- Package Manager 更新只換套件目錄，**不會**把 Lua 寫進 Documents。必須完全關再開 Rhino，再跑任一正式指令才會比對戳記。
- 六支正式指令都會先試拷：`ROOpen`、`ROModels`、`ROCamera`、`ROPoint`、`ROObjects`、`ROCameraPush`（工具列左鍵／右鍵都算）。
- 戳記相同且資料夾還在：完全不動。
- 版號不同或沒有戳記：先清空 lua 資料夾，再拷這版官方 lua／txt 與戳記（這次有拷才開資料夾）。官方熱鍵表會取代已改過的 `R2O_Shortcuts.txt`。不刪整個 `Documents\LoopFlow`。**`2.0.10` 從 Package Manager 更新後跑正式指令，Documents lua 覆寫已實機通過。**
- **正式指令每次都會再試拷檔**（不因「這次 Rhino 已跑過」而跳過）。預設 lua 資料夾不見時（例如被移走）也會再拷。找不到套件 `templates` 時會 MessageBox。開發按鈕（Script Editor／Git）不拷。Octane 裡跑 Lua 不會反向拷 Rhino。
- 找套件 `src`：先 Package Manager 安裝路徑，略過 `.rhinocode/libs` 舊快取。拷檔用既有 `find_templates`，不另外 import 新符號。
- 那不是專案工作資料夾。工作仍以已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2O/` 為準（只留 `live/`、`models/`）。
- 不自動寫入 Octane Preferences。

### 建置路徑

對齊 LoopFlow：Rhino 8 Script Editor `*.rhproj` → `RhinoCode.exe project build` → 刪自動 `.rui` → 複製 `wip/docs/toolbar/` 產品 RUI／`icon.png` → 從 `manifest.yml` 讀 `version:` 寫入 `templates/.loopflow_yak_version` → `yak.exe build`。進包時 RUI 檔名必須與 `.rhp` 相同（例 `LoopFlow R2O.rui`），Rhino 才會自動載入工具列。指令 `language` 必須是物件，不可字串 `"python3"`。不要用手寫 `.rhproj`。

現行 Rhino 8 四顆左鍵產品圖（Open／Models／Camera／Point）含 `<light>`／`<dark>`（`2.0.16`）。來源稿用 `wip/docs/toolbar/inject_theme_svgs.py --light … --dark …` 寫入既有 icon GUID，不寫死 Dropbox 路徑，也不改 GUID。產品圖不要再靠 `fill-dark` 自動反白。分頁小圖不在這份對應裡。

**建包規則（禁止再犯）：** `build.ps1` 必須從 `manifest.yml` 讀版號寫戳記，禁止寫死舊版號。升 `manifest.yml` 卻沒重跑建包、或建包寫死戳記，Package Manager 更新後正式指令會以為不用拷 Lua。`2.0.8` 曾把戳記寫死成 `2.0.6`，升版後 Documents lua 沒被覆寫。
