### Octane（開發期 Lua 入口）

- **對外**仍是 Studio+ 跑 Lua／shortcut（不是 Blender 式「裝一個套件裡一堆按鈕」）。
- **Git 原始碼**：`wip/src/octane/entrypoints/`。`R2O_Camera.lua`／`R2O_Point.lua` 已接消費；Authoring 四支 Auto 已自 1.x 原樣列入同層；`R2O_Open.lua` 仍為空殼。
- **Octane 測試執行位置**：`<LOOPFLOW_R2O_WORKFILES_ROOT>\_LoopFlow_Config\loopflow_R2O\lua\`  
  家中即 `E:\Dropbox (個人)\LoopFlow_Series\Workfiles\WIP_R2O\_LoopFlow_Config\loopflow_R2O\lua`（公司換 `D:\Dropbox\...`）。  
  換機 pull 後跑 `wip/tools/deploy_dev_lua.ps1` 拷過去。快捷鍵指這層，**不要**蓋 1.x AppData Lua。
- 空殼：`R2O_Open.lua`（Octane 端無 Health；Rhino `ROOpen` 已接）。`R2O_Camera.lua`／`R2O_Point.lua` 已接主鏈。Models／Objects 無 LiveLink Lua。
- 熱鍵：同層 `__Open_Shortcuts.lua`、`__Setup_Shortcuts.lua`、`R2O_Shortcuts.txt`。deploy **不覆蓋**已有熱鍵表；拷完 Lua 後再跑 Setup，並重掃 Octane 腳本資料夾。**新增腳本先填 1.x 預設鍵**（見 `資料契約.md`）。Authoring 四支已列入 Git 熱鍵表（`Alt+A`／`Shift+M`／`Ctrl+T`／`Ctrl+Shift+T`）；既有工作檔表須手動補行。
- Camera：Ctrl+Q／跑 `R2O_Camera.lua`＝套用一次即結束（ED-19 已試 realtime，Lua 會鎖 UI，改回 1.x）。
- Point：跑 `R2O_Point.lua`＝套用一次；Scatter 在場景根。**家中實機已通過**。
- Models：**無** LiveLink。Rhino `ROModels` 三步視窗後寫 `models/R2O.usdz`（`_-Export` 一律 `%TEMP%` 再拷 pending）。Octane 第一次載入該檔；材質接口＝Rhino 材質名稱（同名＝同一接口）。之後覆寫同一檔則 **關再開** 才重讀。不要按 Reload mesh／Load new mesh（Studio+ 2026.4 限制）。
- Objects：**無** LiveLink。Rhino `ROObjects` 先選再匯，寫 `models/R2O_Objects_YYMMDD_HHMMSS.usdz`（不覆蓋）。Octane 自行載入該 USDZ。
- Open：Rhino `ROOpen` 英文對話框四顆等寬 **Open Config → Open live → Open models → Open Docs**。摘要含 Camera／Point／Models／Objects last-good。Open Docs 開 GitHub `docs/README.md`（開發期 `v2-development`）。Octane `R2O_Open.lua` 仍為空殼。
- Authoring 工具維持獨立腳本組（四支 Auto 與 LiveLink 同資料夾、不同職責），不塞進 LiveLink 主鏈、本輪不擴功能。**家中已通過**。操作見 `工作流程.md`：對齊 nodes（Alt+A）／USDZ 材質轉 Universal（Shift+M）／建 PBR 材質球（Ctrl+Shift+T）／材質球內切 UV（Ctrl+T）。

### 安裝格式

- 主格式：`.yak`（Rhino 8 Package Manager）。GitHub Release 與 Package Manager **同一份** `.yak`，另附 checksum。不做 RHI。
- **只包 Rhino**：正式指令、`.rhp`、產品工具列 RUI。
- **不進 yak**：Octane Lua／shortcut、Authoring 腳本。Octane 端由 GitHub Release／README 安裝。
- Package Manager **說明**必須放本 repo GitHub 連結，指向 Octane 安裝方式。
- 畫面名稱：**`loopflow Rhino to OctaneRender Sync`**。檔名型式對齊 `loopflow-2.0.7-rh8_0-win.yak`（例 `loopflow-rhino-to-octanerender-sync-2.0.0-rh8_0-win.yak`）。
- 開發期仍用 ScriptEditor＋repo；進包後按鈕打正式 `! _ROCamera` 等（見 `rhino指令.md`）。

### GitHub tag（不覆寫）

| tag | 意義 |
|---|---|
| `v1.0.0` | 已發布 1.x；永不移動 |
| `v2.0.0` | 第一次公開 2.0 功能版；永不移動、不覆寫 |

同一個 tag 代表該次**整份 repo**（含 GitHub 上的 Octane Lua）；yak 仍只含 Rhino。

公開中文使用說明初稿在 `wip/docs/readme/`（`README_zh-TW.md`、`USER_GUIDE_zh-TW.md`、`COMMANDS_zh-TW.md`），**你確認後**才寫英文、才取代 repo 根目錄 1.x 文件。現有 `docs/USER_GUIDE*` 維持 1.x。Package Manager 上架前再確認文案／名稱／圖示／版號。
