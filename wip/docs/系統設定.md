### Octane（開發期 Lua 入口）

- **對外**仍是 Studio+ 跑 Lua／shortcut（不是 Blender 式「裝一個套件裡一堆按鈕」）。
- **Git 原始碼**：`wip/src/octane/entrypoints/`。`R2O_Camera.lua`／`R2O_Point.lua` 已接消費；Authoring 四支 Auto 已自 1.x 原樣列入同層；`R2O_Open.lua` 仍為空殼。
- **Octane 測試執行位置**：`<LOOPFLOW_R2O_WORKFILES_ROOT>\_LoopFlow_Config\loopflow_R2O\lua\`  
  家中即 `E:\Dropbox (個人)\LoopFlow_Series\Workfiles\WIP_R2O\_LoopFlow_Config\loopflow_R2O\lua`（公司換 `D:\Dropbox\...`）。  
  換機 pull 後跑 `wip/tools/deploy_dev_lua.ps1` 拷過去。快捷鍵指這層，**不要**蓋 1.x AppData Lua。
- 空殼：`R2O_Open.lua`（Octane 端無 Health；Rhino `ROOpen` 已接）。`R2O_Camera.lua`／`R2O_Point.lua` 已接主鏈。Models／Objects 無 LiveLink Lua。
- 熱鍵：同層 `__Open_Shortcuts.lua`、`__Setup_Shortcuts.lua`、`R2O_Shortcuts.txt`。兩支腳本優先用 `debug.getinfo` 推導所在資料夾；若 Octane 未提供 `@…lua` 路徑，則備援 `%USERPROFILE%\Documents\LoopFlow\Rhino to OctaneRender Sync\lua`（該層須有 `R2O_Shortcuts.txt`）。失敗／完成改用可見 `MessageBox`，不只 Console `print`。deploy **不覆蓋**已有熱鍵表；拷完 Lua 後再跑 Setup，並重掃 Octane 腳本資料夾。修過 Git 腳本後須 **ROOpen（或重拷 Documents lua）** 再測。**新增腳本先填 1.x 預設鍵**（見 `資料契約.md`）。Authoring 四支已列入 Git 熱鍵表（`Alt+A`／`Shift+M`／`Ctrl+T`／`Ctrl+Shift+T`）；既有工作檔表須手動補行。
- Camera：Ctrl+Q／跑 `R2O_Camera.lua`＝套用一次即結束（ED-19 已試 realtime，Lua 會鎖 UI，改回 1.x）。
- Point：跑 `R2O_Point.lua`＝套用一次；Scatter 在場景根。**家中實機已通過**。
- Models：**無** LiveLink。Rhino `ROModels` 三步視窗後寫 `models/R2O.usdz`（`_-Export` 一律 `%TEMP%` 再拷 pending）。Octane 第一次載入該檔；材質接口＝Rhino 材質名稱（同名＝同一接口）。之後覆寫同一檔則 **關再開** 才重讀。不要按 Reload mesh／Load new mesh（Studio+ 2026.4 限制）。
- Objects：**無** LiveLink。Rhino `ROObjects` 先選再匯，寫 `models/R2O_Objects_YYMMDD_HHMMSS.usdz`（不覆蓋）。Octane 自行載入該 USDZ。
- Open：Rhino `ROOpen` 英文對話框四顆等寬 **Open Config → Open live → Open models → Open Docs**。摘要含 Camera／Point／Models／Objects last-good。Open Docs 開 GitHub `docs/README.md`（`main`）。Octane `R2O_Open.lua` 仍為空殼。

### 安裝格式

- 主格式：`.yak`（Rhino 8 Package Manager）。GitHub Release 與 Package Manager **同一份** `.yak`，另附 checksum。不做 RHI。
- **含 Rhino 與 Octane Lua**：正式指令、`.rhp`、產品工具列 RUI、`templates/` 裡的 Lua（含 Authoring 與熱鍵表）。第一次跑任一產品指令拷到「文件\LoopFlow\Rhino to OctaneRender Sync\lua」。
- 畫面名稱：**`loopflow Rhino to OctaneRender Sync`**。檔名型式對齊 `loopflow-2.0.7-rh8_0-win.yak`（例 `loopflow-rhino-to-octanerender-sync-2.0.1-rh8_0-win.yak`）。
- 開發期仍用 ScriptEditor＋repo；進包後按鈕打正式 `! _ROCamera` 等（見 `rhino指令.md`）。
- 不自動寫入 Octane Preferences。使用者把 Script directory 指到 lua 資料夾（路徑可任意，整包須在一起）。換版清空 lua 資料夾後會放入這版官方 `R2O_Shortcuts.txt`。

### 本機「文件\LoopFlow」戳記

第一次跑任一產品指令，把 yak `templates/` 裡的 Lua 拷到 `%USERPROFILE%\Documents\LoopFlow\Rhino to OctaneRender Sync\lua\`：

- 戳記＝套件版號；版號相同且已有檔則完全不動。
- 版號不同或沒有戳記：先清空 lua 資料夾，再拷這版官方 lua／txt 與戳記（這次有拷才開資料夾）。官方熱鍵表會取代已改過的 `R2O_Shortcuts.txt`。不刪整個 `Documents\LoopFlow`。
- 那不是專案工作資料夾。工作仍以已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2O/` 為準（只留 `live/`、`models/`）。
- 不自動寫入 Octane Preferences。

### 建置路徑

對齊 LoopFlow：Rhino 8 Script Editor `*.rhproj` → `RhinoCode.exe project build` → 刪自動 `.rui` → 複製 `wip/docs/toolbar/` 產品 RUI／`icon.png` → `yak.exe build`。進包時 RUI 檔名必須與 `.rhp` 相同（例 `LoopFlow R2O.rui`），Rhino 才會自動載入工具列。指令 `language` 必須是物件，不可字串 `"python3"`。不要用手寫 `.rhproj`。產品 RUI 另存，不要用 RhinoCode 自動產生那份去改使用者工具列套件。
