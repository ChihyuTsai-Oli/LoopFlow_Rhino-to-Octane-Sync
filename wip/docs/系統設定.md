## 開發測試入口

### Rhino

- `rhino指令.md` → `wip/src/rhino/entrypoints\`（入口只轉交、無業務邏輯；檔案後續建立）。
- 暫定：`R2O_Models`、`R2O_Scatter`、`R2O_Point`、`R2O_Camera`、`R2O_Open`。

### Octane（開發期 Lua 入口）

- **對外**仍是 Standalone 跑 Lua／shortcut（不是 Blender 式「裝一個套件裡一堆按鈕」）。
- **對內**原始碼可模組化（`wip/src/octane/`：LiveLink／foundation）；先驗證 `require`／reload，不可靠則 build 打成可單獨執行腳本再裝。
- 開發期可先放 **空殼 Lua 入口**（Camera／Point／Health 等：按了只報「尚未實作」或只做路徑檢查），再於垂直任務接功能；對齊 Rhino entrypoints／XF-ED-03＝B。
- 使用**隔離** scripts／shortcut／scene，不覆蓋已發布 1.x。
- Camera：2.0 可開關 real-time（關＝Ctrl+Q／跑一次）；Models **無** LiveLink（手動置換 USDZ）。
- Authoring 工具維持獨立腳本組，不塞進 LiveLink 空殼主鏈。
