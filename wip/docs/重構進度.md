## Golden workflow 基準

- 執行時根：已存檔 `.3dm` 旁 `_LoopFlow_Config/loopflow_R2O/`（與 R2B 同型）。**家中中文路徑已通過相機與點位實機**（只標這兩條＋工作檔根，不標整條產品 Golden）。
- 相機：Rhino `ROCamera`／`ROCameraPush` 持續寫 `live/camera.json`；Octane Ctrl+Q／跑 `R2O_Camera.lua` 套用一次。
- 點位：Rhino `ROPoint` 寫 `live/point.json`；Octane 跑 `R2O_Point.lua` 套用一次。Scatter 在場景根、前綴 `R2O_Point_`。圖層根 `R2O::`。指標 `%APPDATA%\LoopFlow\R2O\current_project.json`。
- 模型：Rhino `ROModels` 三步視窗後寫 `models/R2O.usdz`（`_-Export` 一律 `%TEMP%` 再拷 pending）；Octane **無 LiveLink**。第一次載入該檔；之後覆寫同一檔則關再開 Octane（不要 Reload／Load new mesh）。材質接口＝**Rhino 材質名稱**（同名＝同一接口，不是圖層名）。家中已確認關再開後接線仍在。
- 使用操作序：Models → Camera → Point → Objects。Objects：`ROObjects` → `models/R2O_Objects_時戳.usdz`（不覆蓋；無 Lua）。
- Open：Rhino `ROOpen` 四顆等寬 Config／live／models／Docs；不寫交換檔。Open Docs＝R2O GitHub `docs/README.md`（開發期 `v2-development`）。Octane Open Lua 仍空殼。
- Authoring：四支 1.x Auto 原樣在 `lua/`；家中 **已通過**。對齊 nodes（Alt+A）／USDZ 材質轉 Universal（Shift+M）／建 PBR 材質球（Ctrl+Shift+T）／材質球內切 UV（Ctrl+T）。不擴功能。
- 發布：yak 只含 Rhino；Package Manager 畫面名 `loopflow Rhino to OctaneRender Sync`；本機 `0.1.0` 正式指令 **已通過**；`v2.0.0` 永不移動；1.x `v1.0.0` 不碰。
