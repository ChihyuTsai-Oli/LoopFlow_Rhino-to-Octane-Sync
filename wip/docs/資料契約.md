## 共通規則

- Python 與 Lua 共用 versioned schema／fixtures。
- **軟體介面一律英文**（Rhino 對話框／彈窗、Octane 腳本提示）。文件與程式註解仍用繁中。
- Consumer 僅 parse＋apply 成功才更新狀態。
- pending→validate→atomic；last-good 保護。
- 來源 `.3dm` 狀態還原；Objects **不**搬來源物件。
- Point 身分以完整路徑 `type_id` 為準（**不再**要求「終端圖層名全域唯一」；那是 1.x 舊規則）。
- 資產用 Block 建議與 Point 掃描圖層分開（例如 `USD::`）。

執行時路徑與 R2B 相同：設定、相機／點位 JSON、USDZ 都在工作檔旁 `_LoopFlow_Config/loopflow_R2O/`。家中（`Dropbox (個人)`）已通過：USD 進 Octane、跑 Lua、Lua 讀 `camera.json`／`point.json`。**不另開英文交換根。** 後續 Lua 讀 JSON 必須沿用同一套開檔（8.3／`CreateFileW`），禁止裸 `io.open`。

AppData 只放 XF-ED-04「目前專案指標」（這台電腦正在做哪案），不放 live／models。

### 相機 JSON（schema_version = 1）

欄位對齊 1.x Lua：`position`／`target`／`up_vector` 為公尺 Y-up `[x,y,z]`（Rhino `(x,z,-y)`）；`fov_degrees` 由 35mm 等效鏡頭算出，感光寬 **36mm**，鏡頭 ≤ 0 退回 50mm。另含 `producer`、`document`、遞增 `revision`。Lua **只 parse JSON**，禁止 `loadfile()` 同步檔。

Octane 目標：**恰好一台**已從 Render Target Expand 的 Thin Lens。零台或多台停止並英文說明，不猜第一台。

Camera 消費（ED-19）：**2.0 已試 realtime**（視窗／Sleep／Timer 回呼）。Studio+ 2026.4 只要 Lua 還在跑就鎖整套介面（與 1.x 相同）。**現行：Ctrl+Q／跑 `R2O_Camera.lua` 套用一次即結束。** Rhino 仍持續寫 `camera.json`。

Lua 讀中文工作檔路徑：指標帶 Windows 8.3 `config_root_short`；再不行才用 UTF-16 開檔。不要用會對 UTF-8 路徑失敗的 `io.open` 當唯一手段。

### 點位 JSON（schema_version = 1）

掃圖層根 **`R2O::`**（根層 `R2O` 本身不掃）。`type_id`／`source_layer_path`＝完整圖層路徑；`display_name`＝末層；`kind`＝`point` 或 `block`；`xform`＝12 個數字（1.x 3×4 列優先：Point 為位置＋單位矩陣，Block 為 `BlockInstanceXform` 軸轉換，公尺、`(x,z,-y)`）。`guid` 僅診斷。Octane 節點名＝`R2O_Point_`＋`::` 換成 `__`（中文保留）。兩個不同路徑洗成同一節點名→整批停止。同末層、不同父＝兩個節點。改圖層名＝新類型，舊受管節點在下次成功套用後刪除。

Octane 消費：跑 `R2O_Point.lua` 套用一次即結束（無預設熱鍵）。Scatter **建在場景根**（自帶 Geometry 輸入／輸出，不必炸開）。1.x 的 `R2O_Point` nodegraph 沒有接腳，炸開後節點離開群組，二次套用會對空群組做事——2.0 不再新建該群組。**更新／刪除**範圍＝前綴 `R2O_Point_` 的受管 Scatter（含已炸開到場景上的）。已有節點就地改 `A_TRANSFORMS`、不搬位置。空 `items` 仍套用（清掉已刪類型）。禁止 `loadfile()`。

### Models USDZ（檔名已凍結）

`ROModels` 三步（英文介面，對齊 R2B）：(1) 排除記號，預設 `//`，圖層 FullPath 含此文字則不匯出，空白＝不排除；(2) 階層圖層樹選父圖層（含子圖層、可捲動）；(3) CheckListBox 勾幾何類別，Point／Curve 預設不勾，其餘預設勾。含隱藏／鎖定。**不**自動存 `.3dm`。匯出前暫時顯示／解鎖、暫時把材質來源改為圖層；結束後還原可見／鎖定／材質來源／選取／`doc.Modified`。

寫入 `models/R2O.usdz`：Rhino `_-Export` **一律**寫 `%TEMP%\R2O.usdz`（ASCII；失敗則 `%TEMP%\R2O_r1.usdz`）→ Python 拷到 `R2O_pending.usdz` → 把 Mesh 上共用的 `rel material:binding` 提升到圖層 Xform → zip 內 ASCII 檔名維持／改為 `R2O.usda` → 驗證 → atomic 換成 last-good。不把中文／括號路徑丟進指令列，也不再用 8.3 原地寫 Dropbox（那條路徑 `command=True` 卻寫不出檔）。**Octane 露出的材質接口跟 Rhino 材質名稱走，不是圖層名。** 不同圖層、不同物件，只要 Rhino 材質名稱相同，就是同一個接口；要分開接就必須用不同材質名。R2O **不**像 R2B 那樣把圖層材質改名成 `父::末端`，沿用你在 Rhino 設好的名稱。後處理或驗證失敗＝整次失敗，舊檔不動。沒有 USDA（只剩 usdc）＝失敗。空範圍／取消任一步，不發布。無 ModelDir 覆寫。不要為了重匯而出刪 last-good。

Octane **沒有** Models Lua。第一次把場景載入這份 last-good。之後 Rhino 覆寫同一檔：**不要**按 Inspector 的 Reload mesh 或 Load new mesh（當新模型、接線會斷）。**關掉 Octane 再開**，已連結的 USDZ 會在啟動時跟上；**Rhino 材質名稱不變**則同一接口仍接得上。家中 Studio+ 2026.4 已實機確認；視為 Octane 開著時不重讀連結 USDZ 的限制，2.0 不做自動重載。改 Rhino 材質名＝新接口。1.x 公開說明曾寫 UUID 跟圖層名走；2.0 以這次實機為準。

### Objects USDZ（檔名已凍結）

`ROObjects` 對齊 R2B Objects：**先選取、再跑指令**。讀目前選取，不跳選取視窗。沒選取＝擋住。不限 Block；一次匯出**一份** USDZ。**不**搬原點、不炸開 Block。

寫 `models/R2O_Objects_YYMMDD_HHMMSS.usdz`（本機 24 時制）：`_-Export` 一律 TEMP（正式時戳檔名）再拷 pending → 材質提升（zip 內 USDA 檔名＝正式 stem）→ 驗證 → atomic。**不覆蓋**舊檔；同秒碰撞則檔名加一秒。不自動存來源 `.3dm`。結束後選取與 `doc.Modified` 還原。

Octane **沒有** Objects Lua。每次是新檔，自己載入該 USDZ 當獨立組件。不要 Reload／Load new mesh。Point 在場景根建的 Scatter 節點仍由點位通道負責，與本指令檔名無關。

Octane 熱鍵：`lua/R2O_Shortcuts.txt` 為自訂來源；`__Open_Shortcuts.lua` 打開該檔、`__Setup_Shortcuts.lua` 寫入各腳本 `-- @shortcut`。deploy 不覆蓋已存在的熱鍵表；拷完 Lua 後需再跑 Setup 並重掃 Octane 腳本資料夾。**新增功能時先填 1.x 預設鍵**（舊版沒有就留空白），不要自己發明預設；使用者之後仍可改表。

| 2.0 腳本 | 1.x 腳本 | 預設熱鍵 |
|---|---|---|
| `R2O_Camera.lua` | `LiveLink_R2O_Camera` | `Ctrl + Q` |
| `R2O_Point.lua` | `LiveLink_R2O_Point` | （空白） |
| `R2O_Open.lua` | （無對應熱鍵） | （空白） |
| `Auto_Align_Nodes.lua` | `Auto_Align_Nodes` | `Alt+A` |
| `Auto_Convert_StdSurf_to_Universal.lua` | `Auto_Convert_StdSurf_to_Universal` | `Shift+M` |
| `Auto_PBR_Switch_UV.lua` | `Auto_PBR_Switch_UV` | `Ctrl+T` |
| `Auto_PBR_Universal.lua` | `Auto_PBR_Universal` | `Ctrl+Shift+T` |

Authoring 四支腳本尚未搬進 2.0；搬進來時把上表鍵寫進 `R2O_Shortcuts.txt` 與 `-- @shortcut`。

Package Manager 畫面名：**`loopflow Rhino to OctaneRender Sync`**（已決；官方拼法含 e）。yak 只含 Rhino；Octane Lua／Authoring 不進包。

公開使用說明改寫等 **本產品程式完成後再與 R2B 一起寫**。現有 `docs/USER_GUIDE*` 維持 1.x；`docs/README.md` 只當入口。

`config.json` 本批只保留檔名；Open **不**讀寫設定欄位。
