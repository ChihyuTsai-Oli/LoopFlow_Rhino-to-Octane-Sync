LoopFlow Rhino to OctaneRender Sync: one-way model, camera, and point sync from Rhino 8 to OctaneRender. Update models without breaking material links. A layer with no material uses its layer path, with Chinese turned into underscores. Point scatters pack into the R2O_Point node graph with R2O_Point_Geometry. Each apply lines them up left to right by name.
